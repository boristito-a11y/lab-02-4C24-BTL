# lab-02-4C24-2024-JGM
Descripción breve del proyecto
Laboratorio sobre Control de Versiones, utilizando Git y GitHub para gestionar cambios y mantener un historial del proyecto. 
## Getting Started
Instrucciones para empezar el proyecto
Clonar el repositorio:
1. git clone <https://github.com/boristito-a11y/lab-02-4C24-BTL.git>
2. Entrar a la carpeta:
cd lab-02-4C24-2024-JGM
3. Realizar cambios y guardarlos:
git add .
git commit -m "Cambios realizados"
git push
